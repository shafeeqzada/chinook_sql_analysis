# Chinook SQL Analysis

SQL analysis of the Chinook music store database using PostgreSQL and pgAdmin4.

## Tools
- PostgreSQL
- pgAdmin4

## Dataset
Chinook database: https://github.com/lerocha/chinook-database

## Skills Used
- SELECT, WHERE, DISTINCT, ORDER BY, LIMIT
- GROUP BY, HAVING, aggregate functions
- JOINs (one-to-many, multi-table)
- Subqueries
- CTEs
- Window functions (RANK, running total)

## Questions Solved
**Basic**
1. How many customers are there in total?
2. Which countries do the customers come from?
3. Which tracks cost more than $1?

**GROUP BY**
4. How many customers are there in each country?
5. What is the total revenue for each country?
6. How many tracks are there in each genre?

**JOIN**
7. Who are the top 10 customers by total spending?
8. What are the 10 best-selling tracks?
9. What are the total sales for each genre?

**Advanced**
10. What is the monthly revenue?
11. Which customers spent more than the average customer?
12. Who is the top customer in each country?
13. What is the running total of revenue over time?
